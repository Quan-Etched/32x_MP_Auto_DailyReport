The top table is a faithful copy of the module line's own tracker tab — the line's judgement of what passed, not a re-derivation from the API. The L10 and L11 tables under it have no such sheet behind them; they are rebuilt from the controllers, and each says so above its columns. Test links go to pega3, pega4 and pega5 respectively, all of which ask for an ESVM login first.

L11 is still in bring-up, and its table shows two things the others do not. Aborted is counted apart from "not run": a rack that tried for an hour and gave up is not a rack that never started. And ×n beside a verdict is how many times that stage ran on that rack today — the verdict shown is the last of them.

There is no OCP Logs column because OCP has no per-run URL: its RUNS tab keeps the filter and the selection in memory, so every run is the same address. To find one there, filter by the DUT serial and the date — or use the run table, which reads the same records and does have a link per run.
