What this dashboard needs from systems it does not own — a route, a certificate, an IAM grant, a field in someone else's API, or a decision. The checkable ones check themselves on every build, so a status here is as old as the page and no older.

Anything we can do ourselves lives in STATUS.md instead — this page is only for asks that need someone else. Add one in src/factory/requests.py; give it a probe if the answer can be checked rather than asserted.
