One row per unit run, straight from the station controllers — so a fixture of eight modules is eight rows, not one. Status is the controller's own verdict. Attempt counts that unit's visits to that station across everything collected, not just the window you picked, so a row saying attempt 3 means the third overall.

The day column here is UTC. The run table's own day column is factory-local (America/Los_Angeles), which is deliberate there and would put a run at 17:00 local on the previous day — worth knowing if you compare the two by eye.
