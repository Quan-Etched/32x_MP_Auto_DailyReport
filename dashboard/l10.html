L10 tracker

← Station yield ← Module tracker Raw runs → Feature requests → Test flow →

One row per chassis per day, across the four L10 stages. Built entirely from pega4, which drives stations pt2_l10_station6 and 7 — there is no hand-kept sheet for L10, so nothing here is the line's own record. pega4 asks for an ESVM login before it will show a run.

No Jira column: the module tracker takes its ticket keys from the line's spreadsheet, and L10 has none — an always-empty column would be worse than an absent one. An L10 run tests one chassis rather than eight slots, so a unit's failures are every failing test in its run.
