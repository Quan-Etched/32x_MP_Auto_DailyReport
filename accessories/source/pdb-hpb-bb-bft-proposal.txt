PDB BFT test item summarization
  ------------------------------------------------------------------------------
  Test item
    Description
    Criterion
  ------------------------------------------------------------------------------
  Address/Preset/AC_FAULT pin test
    Use TFMB GPIO to get the address pin level, check the resistor mount or
    unmount.
    TFMB will get 3.3V or 0V to define pass or fail.

  SMBUS DAT/INT#/CLK pin test
    Use TFMB GPIO to send the high level signal, via PU1 to PSU1-4.
    TFMB will check GPIO get 3.3V level to define pass or fail.

  PWROK pin test
    Use TFMB GPIO to send the high level, via PSU1-4 to PU1.
    TFMB will get correct voltage by PU1 PWROK PIN.

  PS_ON/12VSB/SMART_ON/I_SHARE/RS+/RS- pin test
    Use TFMB GPIO to send the signal, via PU1 to PSU1-4.
    TFMB will get correct voltage by PSU1-4 PS_ON PIN.

  54V/12V pin test
    Use TFMB GPIO to send the signal at PSU1, and get signal at PSU1-4 and
    HPB_PSU2.
    TFMB will get correct voltage by PSU1-4 and HPB_PSU2.
  ------------------------------------------------------------------------------

HPB BFT test item summarization
  ------------------------------------------------------------------------------
  54V output test
    TFMB will control the EN of Hotswap controller of DUT by cable at our
    fixture. And the PG signal will feedback to TFMB if power rail output is
    normal.
    TFMB can get the 3.3V high level signal was pass.

  LED Visually check
    Check LED light.
    Led light was pass, it was fail without light through visual inspection.

  I2C pin test
    TFMB could read MPS i2c register check if power rail level is normal or not
    through cable connected to TFMB.
    Get the correct value from MPS I2C register.

  Reset pin test
    TFMB will send reset to HPB mux. TFMB i2c master could get the I2C bus
    through mux after reset.
    I2C signal will reset. TFMB could check I2C address successfully again.

  12V output test
    DUT will provide 12V to FIXTURE. 12V will feedback to TFMB for checking.
    TFMB get the high level signal was pass.
  ------------------------------------------------------------------------------

Bridge Board Block Diagram                                             [figure]
  Four connector pairs CON1A/B, CON2A/B, CON3A/B, CON4A/B.
  Each pair carries, per position -1 / -2 / -3 / -4:
    ETH0_LN0~3, ETH1_LN0~3, ETH0_LN8~11, ETH1_LN8~11   (TX/RX, RX/TX)
    ETH0_LN4~7, ETH1_LN4~7, ETH0_LN12~15, ETH1_LN12~15 (TX/RX, RX/TX)

Bridge board Test fixture                                              [figure]
  Per connector, the fixture gathers:
    nA_ETH0_LN0-15_P / nA_ETH1_LN0-15_P / nA_ETH1_LN0-15_N (x2) and GND,
    addressed A0..A15, for n = 1..4 and side A / B.

BB Fun. Check
  To attach BB (DUT) with Test fixture. B2B Con attach.
  Bridge board Test fixture: CON1A1B all ETH0 and ETH1 P signal will connect
  together follow the layout signal sequence. Can check all P signal had
  correct solder and not short with GND or N signal. So does all N signal
  design. CON2A2B, CON3A3B, CON4A4B had the same design.

Proposal to increase the test coverage for open circuit — Yibing, 12/30/2025
  Open/short test:  1A -> 1B -> 1B -> 1A
    IN  (Toggle, from GPIO)
    OUT (Monitor, to GPIO)
    Desired: IN=H, OUT=H ; IN=L, OUT=L
  Cascade all P signals to reduce the number of GPIOs.
  Test board: FR-4 or equivalent low speed board.
  Group of _Ps (or Ns).

BB BFT test item summarization
  ------------------------------------------------------------------------------
  Open/short test
    TFMB send the signal to series P/N/GND pins, check following:
      - Series P signals open with series N signals
      - Series P signals open with GND
      - Series N signals open with GND
    All measured signals need to be open from each other.
  ------------------------------------------------------------------------------
