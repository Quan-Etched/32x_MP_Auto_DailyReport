Etched | FATP Process Flow
================================================================================
Inputs: HPB Board · VBB Board · PDB Board
Stations: Inspection · Liquid Station · 2U/4U Assy Station · 6U Assy Station
4U Process:
  Pre-Assy1 Install Coldplate Handles and Bridge board
  Pre-Assy2 Disassemble the 4U Tray
  Pre-Assy3 Assemble Rear Tray Module
  Machine1  Dispensing on Bottom cold plate
  Assy1 Assemble Sohu Module on Bottom Coldplate
  Assy2 Assemble Sohu Link Cable
  Assy3 Assemble PCIe harness
  Assy4 Assemble Power harness
  Assy5 Arrange Hoses of Sohu Module
  VI1   4U - Final Visual Inspection
2U Process:
  Pre-Assy1 Remove parts
  Pre-Assy2 Attach the Labels on MCIO cable
  Pre-Assy3 Assemble PDB Module
  Pre-Assy4 Assemble Switch Board Module and Riser Module
  Pre-Assy5 Assemble Fan LB Bracket L & R
  Pre-Assy6 Assemble IO module and HDD Cage Module
  Pre-Assy7 Assemble Middle Fan module
  Assy1 Install MB and Switch Board
  Assy2 Install CPU, DIMM, and Cold plate
  Assy3 Install PDB and MCIO cables
  Assy4 Install Riser Module & Fan LB Module
  Assy5 Install BPB and fan cage
  Assy6 Install PSU and HDD
  2U Firmware update (Liquid)
  2U Function test (Liquid)
  2U Run-in (Liquid)
  VI1 2U - Final Visual Inspection
6U Process:
  Insert 4U tray into 2U System
  6U L10 System Function test
  6U L10 System Run-in test
  Hi pot test
  4U and 2U VI
  OQC

Production Failure Analysis Flow
================================================================================
Production Test -> PASS -> Move to next stage -> OK2SHIP
Production Test -> FAIL -> Report to Pega FA team for first triage
  -> Root Cause Identification -> RC  -> Documentation
                               -> NTF -> Reach out to Etched for further FA
  -> Report to Etched review the FA
